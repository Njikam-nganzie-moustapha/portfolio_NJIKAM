# Portfolio Ultra-Moderne - Njikam Nganzie Moustapha

This is a modern portfolio web app built with [Vite](https://vitejs.dev/).

## Project structure

The frontend code is in the `src` directory and is built with React, TypeScript, and Tailwind CSS.

## Running the app

Install dependencies:
```sh
npm install
```

Start the development server:
```sh
npm run dev
```

## Features

- Modern portfolio layout
- Projects, gallery, contact, and about pages
- Responsive design
- Theme and language toggles

---

This project is frontend-only and does not require a backend.
